# Методичка

В этой папке лежит оригинальный файл **методических рекомендаций** по контрольной работе: `metodichka.docx`.

## ⚠️ Агент обязан прочитать этот файл перед началом любой работы

Файл содержит:
- Требования к контрольной работе в целом (какие технологии обязательны, что должно быть в отчёте, как оформляются скриншоты и т.д.);
- Описание всех 5 вариантов заданий (вариант выбирается по первой букве фамилии студента);
- Требования к оформлению отчёта по стандартам УрГЭУ.

**Наш вариант — Вариант 2 («Доска объявлений»).** Полный текст задания по варианту 2 находится внутри `metodichka.docx`, а краткое изложение — в корневом [README.md](../README.md) репозитория.

Если в процессе работы возникают сомнения по требованиям (что именно нужно реализовать, что должно быть в отчёте, как оформлять скриншоты) — сверяться с этим файлом, а не додумывать самостоятельно.
