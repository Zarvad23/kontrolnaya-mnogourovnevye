# Программная часть

Здесь размещается весь код доски объявлений: PHP-файлы, HTML, SQL-скрипт для создания базы данных.

Перед началом работы — обязательно прочитать [методичку](../metodichka/) и [корневой README](../README.md).

## Что нужно реализовать (Вариант 2)

- Пользователь заходит на сайт, выбирает рубрику (категорию) и размещает в ней своё объявление.
- Список объявлений выводится по рубрикам.
- Раз в сутки пользователь может нажать кнопку «Поднять» рядом со своим объявлением — после этого объявление перемещается наверх списка в своей рубрике. Повторно поднять то же объявление раньше чем через 24 часа — нельзя.
- Настройка базы данных MySQL: таблицы для объявлений и рубрик (и пользователей, если делается авторизация).

## Правила стиля кода (соблюдать строго)

1. **Простота.** Только базовые конструкции PHP: обычные `if`/`else`, циклы `for`/`while`, обычные функции. Никаких ООП-паттернов, фреймворков (Laravel и т.п.), Composer-пакетов, PDO с продвинутыми техниками — используем простой `mysqli` в процедурном стиле.
2. **Комментарии на русском.** Простым языком, как заметки для себя: например `// тут проверяем что поля не пустые`, `// подключаемся к базе`.
3. **Именование переменных «как студент».** Транслит или простая смесь рус/англ: `$polzovatel`, `$spisok_obyav`, `$kategoriya`, `$data_dobavleniya`, `$posledniy_podnyatie` и т.п. Не использовать идеальный чистый английский нейминг (`$user`, `$categoryList`) — это выдаёт «не студенческий» код.
4. **Не переоптимизировать.** Можно писать не самым эффективным способом, дублировать немного кода, если так проще и понятнее — это нормально для уровня задания.
5. **Уровень: студент после учебника + видеогайдов.** Не идеальный профессиональный код, но и не бессмысленный мусор — рабочий, читаемый (на базовом уровне) код с логическими ошибками, которые типичны для новичка, недопустим лишь в смысле «совсем не работает».
6. **Интерфейс.** Простая обычная вёрстка HTML/CSS без современных «нейросетевых» признаков (не надо скруглённых на 16px карточек, теней, градиентов, красивых шрифтов Google Fonts, идеальных отступов). Обычная студенческая страница — может выглядеть слегка «топорно», это нормально и даже нужно.
7. Все технологии — строго те, что указаны в методичке: PHP + HTML + MySQL.

## Структура (ориентировочно, можно менять по ходу работы)

```
/code
  index.php          — главная страница, список объявлений по рубрикам
  dobavit.php        — форма добавления объявления
  podnyat.php        — обработка кнопки "поднять"
  vhod.php           — вход/регистрация пользователя (если реализуется)
  db.php             — подключение к базе данных
  baza.sql           — SQL-скрипт создания таблиц
  style.css          — простые стили
```
