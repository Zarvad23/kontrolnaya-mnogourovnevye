## Структура репозитория

```
/metodichka   — оригинальный файл методических рекомендаций (читать первым!)
/code         — программная часть: PHP, HTML, MySQL
/text         — текстовая часть: итоговый отчёт в Word (готовится ПОСЛЕ кода)
```

## Задание по варианту 2 (кратко, полный текст — в методичке)

Реализовать доску объявлений:
- Пользователь заходит на сайт, выбирает рубрику и размещает в ней своё объявление.
- Раз в сутки пользователь может нажать кнопку «поднять» — объявление поднимается наверх списка в своей рубрике.
- Технологии: PHP + HTML, база данных MySQL (согласно методичке).

## Порядок работы

1. Сначала полностью делается программная часть (папка `/code`).
2. После того как код готов и протестирован — пишется отчёт в Word (папка `/text`), со скриншотами БД, таблиц и работы сайта в браузере (с видимой датой и временем), согласно требованиям методички и оформлению УрГЭУ.

## Главное правило ко всей работе — имитация уровня студента

Это принципиально важно и должно соблюдаться в любом коде, который пишется в этом репозитории:

- Код должен быть написан **очень простыми, несложными конструкциями**, без «профессиональных» паттернов, абстракций, фреймворков сверх необходимого.
- Используются только технологии, указанные в методичке (PHP, HTML, MySQL) — без лишних библиотек и современных инструментов сборки.
- Комментарии — **на русском языке**, простым и понятным языком, как будто это заметки для себя («тут делаем то-то», «здесь проверяем пароль» и т.п.).
- Переменные и функции называть так, как их назвал бы русскоговорящий человек, слабо знающий английский (транслитерация или смесь: `polzovatel`, `spisok_obyavleniy`, `kategoriya`, `dobavit_obyavlenie` и т.п.) — не идеальный «чистый» английский нейминг.
- Код может быть не идеально оптимизирован — это нормально, главное чтобы он **работал**.
- Ориентир по уровню: студент, который недавно прошёл учебник и посмотрел десяток видеогайдов и начал пробовать сам — **не** профессиональный уровень, но и **не** полная халтура/бессмыслица.
- Интерфейс сайта должен быть простым, может быть не особо красивым, но обычным — **без** типичных признаков «сделано нейросетью» (без чрезмерно скруглённых углов, без слишком строгой выверенной сетки и «прилизанного» дизайна). Обычный студенческий сайт.

Любой агент, дорабатывающий код в этом репозитории, должен придерживаться этого стиля и не «улучшать» код до профессионального уровня.
