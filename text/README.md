# Текстовая часть (отчёт)

Здесь будет готовиться итоговый отчёт в формате Word (`.docx`) по контрольной работе.

## ⚠️ Эта часть делается ПОСЛЕДНЕЙ

Отчёт пишется только **после того**, как полностью готова и протестирована программная часть в папке [`/code`](../code/).

Перед началом работы над отчётом — обязательно прочитать [методичку](../metodichka/) (там точные требования к содержанию и оформлению отчёта) и [корневой README](../README.md).

## Что должно быть в отчёте (согласно методичке)

- Коды **всех** файлов, задействованных в работе (из папки `/code`).
- Скриншоты структуры базы данных MySQL.
- Скриншоты всех используемых таблиц.
- Скриншоты браузера с результатом работы PHP-скрипта — по всем основным переходам по сайту.
- На скриншотах браузера должны быть видны текущая дата и время.
- Отчёт оформляется по требованиям УрГЭУ к оформлению документов.

## Что должно появиться в этой папке

- Скриншоты (БД, таблицы, браузер) — например в подпапке `screenshots/`.
- Итоговый `.docx` файл с готовым отчётом.
